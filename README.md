# zyx 本地启动

在终端执行：

```bash
cd /Users/vekel/编程/Anime/anime-creation-studio
npm run dev
```

启动后访问：

- 前端：`http://localhost:3000`
- Runtime Gateway：`http://127.0.0.1:8000`

如需单独启动：

```bash
cd /Users/vekel/编程/Anime/anime-creation-studio
npm run dev:web       # 只启动前端
npm run dev:gateway   # 只启动 Gateway
```
